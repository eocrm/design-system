# Avatar xl — Implementation Plan (#330)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `AvatarSize` gains `'xl'` — an 80px avatar (2× lg) with matching initials font, presence dot, and AvatarGroup overlap/overflow support — so the member-card popover never overrides internal `--avatar-size-*` vars again.

**Architecture:** Pure scale extension. New primitives in `tokens.scss` (`--size-xl: 80px`, `--size-presence-xl: 16px`), then the `xl` sibling of every existing per-size token/class across the Avatar family. Method: grep the Avatar directory (+ its tokens block in each file) for every `lg`/`Lg`-suffixed token, class, and map entry, and add the `xl` sibling — that enumeration IS the spec; miss none.

**Decisions locked in:**

- `xl` = 80px (issue asks ~2× lg 40px).
- Initials font: `--avatar-font-size-xl: var(--font-size-2xl)` (24px — continues the xs/sm/md progression at 80px scale).
- Presence dot: **16px, deliberately below the ~0.3 ratio** (which would give 24px) — at 80px the dot is a status indicator, not a feature; 24px dominates the corner. Put this comment in tokens.scss.
- Overlap: same `calc(var(--size-xl) * -0.3)` formula as the other sizes.

**Tech Stack:** React 18, TypeScript, SCSS modules, Vitest + RTL (globals — no describe/it/expect imports).
