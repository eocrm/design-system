# TreeView Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `<TreeView>` — a lazily loaded, WAI-ARIA tree with a `list` (file-explorer) and a `chart` (classic top-down org chart) view — per issue eocrm/design-system#637.

**Architecture:** A pure model (`treeModel.ts`, Node-tested) turns `roots` + `childrenOf` + `expandedIds` + `overflowOf` into a nested item tree (nodes + loading/error/overflow status rows) and a flat list of visible items, and resolves every navigation key to an action (`focus` / `expand` / `collapse` / `activate`) for both views, plus typeahead matching. `TreeView.tsx` renders the nested items (`role=tree` → `treeitem` → `group`), owns the roving tabindex, focus repair and one live region, and dispatches model actions to the consumer callbacks. The two views differ only in CSS and in the key map.

**Tech Stack:** React 19, TypeScript, SCSS modules, `lucide-react` icons (already used by `Rail`, `Accordion`), Vitest (Node `unit` + jsdom `dom` projects), Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-11-tree-view-design.md` — read it before any task.

## Review Focus

- **`childrenOf` returns a new array identity every render** (eocrm maps query data inline): no effect loops, focus must not jump, announcements must not repeat. → Task 3 test "re-rendering with new array identities keeps focus and stays silent".
- **The focused node disappears** (an ancestor collapsed by a toggle click or by the consumer): focus goes to the nearest visible ancestor, never to `body`. → Task 3 test "collapsing an ancestor moves focus to it".
- **`selectedId` names a node that isn't visible** (deep link to a unit whose ancestors are collapsed — eocrm's URL `?unit=`): tab stop falls back to the first item; nothing crashes. → Task 2 test "tab stop falls back to the first item when the selected node is hidden".
- **Duplicate or empty ids / a level that loads empty** (`[]` for a `hasChildren: true` node): no crash; an expanded node with `[]` renders an empty group and ArrowRight/ArrowDown on it does nothing. → Task 1 test "expanded node with no children yields no child items" + Task 1 test "keys are unique per kind".
- **Load-more that returns no new items** (backend total changed): focus stays on the overflow row (or moves to the parent if the row vanished), no stuck pending state. → Task 3 test "load-more that adds nothing leaves focus on a visible item".

```ts
import type { ReactNode } from 'react';

/** One node of a TreeView. */
export interface TreeViewNode {
  /** Stable unique id. */
  id: string;
  /** Accessible name of the row and typeahead text; rendered when `content` is absent. */
  label: string;
  /** Whether the node can expand. Its children may not be loaded yet. */
  hasChildren: boolean;
  /** Rich, non-interactive row content. Visual only: the row is named by `label`. */
  content?: ReactNode;
}

/** Children of a node: the loaded array, `undefined` while loading, `{ error: true }` when the load failed. */
export type TreeViewChildren = TreeViewNode[] | undefined | { error: true };

/** "N more not shown" row at the end of a level. */
export interface TreeViewOverflow {
  /** Visible text and accessible name, e.g. "12 more not shown". */
  label: string;
  /** Makes the row actionable (Enter / click). */
  onLoadMore?: () => void;
  /** A load-more fetch is in flight: the row shows the translated loading text and is inert. */
  loading?: boolean;
}

/** Presentation of a TreeView. */
export type TreeViewView = 'list' | 'chart';

export type TreeItem =
  | {
      kind: 'node';
      key: string;
      node: TreeViewNode;
      level: number;
      parentId: string | null;
      setSize: number;
      posInSet: number;
      expanded: boolean;
      children: TreeItem[];
    }
  | { kind: 'loading' | 'error'; key: string; level: number; parentId: string }
  | {
      kind: 'overflow';
      key: string;
      level: number;
      parentId: string | null;
      overflow: TreeViewOverflow;
    };

export interface TreeModelInput {
  roots: TreeViewNode[];
  childrenOf: (id: string) => TreeViewChildren;
  expandedIds: ReadonlySet<string>;
  overflowOf?: (parentId: string | null) => TreeViewOverflow | null;
}

export type TreeAction =
  | { type: 'focus'; key: string }
  | { type: 'expand'; id: string }
  | { type: 'collapse'; id: string }
  | { type: 'activate'; key: string };

export const nodeKey = (id: string) => `node:${id}`;

function level(
  nodes: TreeViewNode[],
  depth: number,
  parentId: string | null,
  input: TreeModelInput,
): TreeItem[] {
  const out: TreeItem[] = nodes.map((node, i) => {
    const expanded = node.hasChildren && input.expandedIds.has(node.id);
    let children: TreeItem[] = [];
    if (expanded) {
      const kids = input.childrenOf(node.id);
      if (kids === undefined) {
        children = [
          { kind: 'loading', key: `loading:${node.id}`, level: depth + 1, parentId: node.id },
        ];
      } else if (!Array.isArray(kids)) {
        children = [
          { kind: 'error', key: `error:${node.id}`, level: depth + 1, parentId: node.id },
        ];
      } else {
        children = level(kids, depth + 1, node.id, input);
      }
    }
    return {
      kind: 'node',
      key: nodeKey(node.id),
      node,
      level: depth,
      parentId,
      setSize: nodes.length,
      posInSet: i + 1,
      expanded,
      children,
    };
  });
  const overflow = input.overflowOf?.(parentId) ?? null;
  if (overflow) {
    out.push({
      kind: 'overflow',
      key: `overflow:${parentId ?? ''}`,
      level: depth,
      parentId,
      overflow,
    });
  }
  return out;
}

/** Nested items in render order: nodes, plus loading / error / overflow status rows. */
export function buildTree(input: TreeModelInput): TreeItem[] {
  return level(input.roots, 1, null, input);
}

/** Visible items in document order. */
export function flatten(items: TreeItem[]): TreeItem[] {
  return items.flatMap((item) =>
    item.kind === 'node' ? [item, ...flatten(item.children)] : [item],
  );
}

function enter(flat: TreeItem[], i: number): TreeAction | null {
  const item = flat[i];
  if (item.kind !== 'node' || !item.node.hasChildren) return null;
  if (!item.expanded) return { type: 'expand', id: item.node.id };
  const next = flat[i + 1];
  return next && next.parentId === item.node.id ? { type: 'focus', key: next.key } : null;
}

function leave(flat: TreeItem[], i: number): TreeAction | null {
  const item = flat[i];
  if (item.kind === 'node' && item.expanded) return { type: 'collapse', id: item.node.id };
  return item.parentId === null ? null : { type: 'focus', key: nodeKey(item.parentId) };
}

function sibling(flat: TreeItem[], i: number, step: 1 | -1): TreeAction | null {
  const item = flat[i];
  for (let j = i + step; j >= 0 && j < flat.length; j += step) {
    if (flat[j].level < item.level) return null;
    if (flat[j].level === item.level) return { type: 'focus', key: flat[j].key };
  }
  return null;
}

/** Resolves a keyboard key on the item `currentKey` to an action, or null when the key does nothing. */
export function keyAction(
  flat: TreeItem[],
  currentKey: string,
  key: string,
  view: TreeViewView,
): TreeAction | null {
  const i = flat.findIndex((item) => item.key === currentKey);
  if (i < 0) return null;
  const focus = (j: number): TreeAction | null =>
    flat[j] ? { type: 'focus', key: flat[j].key } : null;
  switch (key) {
    case 'Home':
      return focus(0);
    case 'End':
      return focus(flat.length - 1);
    case 'Enter':
    case ' ':
      return { type: 'activate', key: currentKey };
  }
  if (view === 'list') {
    switch (key) {
      case 'ArrowDown':
        return focus(i + 1);
      case 'ArrowUp':
        return i > 0 ? focus(i - 1) : null;
      case 'ArrowRight':
        return enter(flat, i);
      case 'ArrowLeft':
        return leave(flat, i);
    }
    return null;
  }
  switch (key) {
    case 'ArrowDown':
      return enter(flat, i);
    case 'ArrowUp':
      return leave(flat, i);
    case 'ArrowRight':
      return sibling(flat, i, 1);
    case 'ArrowLeft':
      return sibling(flat, i, -1);
  }
  return null;
}

/**
 * Next node whose label starts with `buffer` (case-insensitive), searching after the current item for a
 * single character and from the current item for a longer buffer, wrapping. Status rows are skipped.
 */
export function typeaheadMatch(
  flat: TreeItem[],
  currentKey: string,
  buffer: string,
): string | null {
  const i = Math.max(
    0,
    flat.findIndex((item) => item.key === currentKey),
  );
  const start = buffer.length > 1 ? i : i + 1;
  const needle = buffer.toLocaleLowerCase();
  for (let k = 0; k < flat.length; k++) {
    const item = flat[(start + k) % flat.length];
    if (item.kind === 'node' && item.node.label.toLocaleLowerCase().startsWith(needle))
      return item.key;
  }
  return null;
}
```

```tsx
  {
    view = 'list',
    roots,
    childrenOf,
    expandedIds,
    onExpandedChange,

    buffer: '',
    timer: null,

    ? focusedKey
    : visible(selectedKey)
      ? selectedKey
      : (flat[0]?.key ?? null);

  const focusKey = (key: string) => {
    setFocusedKey(key);
    itemEls.current.get(key)?.focus();
  };

  const activate = (item: TreeItem) => {
    if (item.kind === 'node') onSelect?.(item.node.id);
    // Task 3: error → onRetry, overflow → onLoadMore.
  };

  const run = (action: TreeAction) => {
    if (action.type === 'focus') focusKey(action.key);
    else if (action.type === 'expand')
      onExpandedChange(action.id, true); // Task 3: watch for announcements
    else if (action.type === 'collapse') onExpandedChange(action.id, false);
    else {
      const target = flat.find((i) => i.key === action.key);
      if (target) activate(target);
    }
  };

  const onItemKeyDown = (event: KeyboardEvent<HTMLDivElement>, item: TreeItem) => {
    if (event.target !== event.currentTarget) return;
    if (
      event.key.length === 1 &&
      event.key !== ' ' &&
      !event.ctrlKey &&
      !event.metaKey &&
      !event.altKey
    ) {
      const ta = typeahead.current;
      if (ta.timer) clearTimeout(ta.timer);
      ta.buffer += event.key;
      ta.timer = setTimeout(() => {
        ta.buffer = '';
        ta.timer = null;
      }, 500);
      const match = typeaheadMatch(flat, item.key, ta.buffer);
      if (match) focusKey(match);
      event.preventDefault();
      return;
    }
    const action = keyAction(flat, item.key, event.key, view);
    if (!action) return;
    event.preventDefault();
    event.stopPropagation();
    run(action);
  };

  const onItemClick = (event: MouseEvent<HTMLDivElement>, item: TreeItem) => {
    event.stopPropagation();
    focusKey(item.key);
    activate(item);
  };

  const onToggleClick = (event: MouseEvent<HTMLSpanElement>, item: TreeItem & { kind: 'node' }) => {
    event.stopPropagation();
    focusKey(item.key);
    onExpandedChange(item.node.id, !item.expanded);
  };

      else itemEls.current.delete(item.key);
    },

      if (e.target === e.currentTarget) setFocusedKey(item.key);
    },
    onClick: (e: MouseEvent<HTMLDivElement>) => onItemClick(e, item),
    style: { '--tree-view-level': item.level - 1 } as React.CSSProperties,
  });

      const { node } = item;
      return (

          key={item.key}
          {...common(item)}

              aria-hidden="true"

          </div>

              {item.children.map(renderItem)}
            </div>
          )}
        </div>
      );
    }
    if (item.kind === 'loading') {
      return (
        <div
          key={item.key}
          {...common(item)}
          className={styles.item}
          aria-label={t('treeView.loading')}
          aria-disabled="true"
          data-kind="status"

          <div className={styles.row}>
            <span className={styles.toggle} aria-hidden="true">
```

### Task 3: Async UX — error/overflow rows, focus repair, announcements

**Files:**

- Modify: `packages/design-system/src/components/TreeView/TreeView.tsx`
- Modify: `packages/design-system/src/components/TreeView/TreeView.test.tsx`

**Interfaces:**

- Consumes: Task 2's `activate`, `run`, `focusKey`, `renderItem`, `common`, `flat`, `items`; Task 1's `TreeItem` kinds `error` / `overflow`.
- Produces: final behaviour of `onRetry`, `overflowOf`, the live region (`LiveRegion` from `../LiveRegion`).

Behaviour (spec "Status rows", "Focus", "Announcements"):

1. **Error row**: name and text `"{loadError}. {retry}"` when `onRetry` is passed (actionable: Enter/Space/click → `onRetry(parentId)`), else `loadError` with `aria-disabled="true"`. Text styled `.status[data-error]`; the "Retry" part rendered as `<span data-action>` inside it when actionable.
2. **Overflow row**: name and text = `overflow.label`; when `overflow.loading` → name and text `t('treeView.loading')` with `aria-disabled="true"` and the `CircularProgress` in the toggle slot; actionable when `onLoadMore && !loading` (text gets `data-action`); otherwise `aria-disabled="true"`. Root-level overflow renders after the last root.
3. **Pending focus**: when the user retries or loads more, remember `{ parentId, count }` (count = number of node children of `parentId` currently visible; 0 for retry). After each render (`useEffect` on `flat`), if that level now has more than `count` node children, focus the child at index `count` and clear. If the level has no loading/error/overflow-loading status left and no new children (load-more returned nothing, or retry returned `[]`), clear and — only if the focused item is no longer visible — focus the parent (or the first item for the root level).
4. **Focus repair**: keep a ref `parents: Map<key, parentKey | null>` from the previous render (built from `flat`). In a `useLayoutEffect`, if `focusedKey` is no longer visible AND the tree had focus (`rootEl.contains(document.activeElement)` or `document.activeElement === document.body` while `hadFocus.current` — track `hadFocus` via root `onFocus` / `onBlur` with `relatedTarget` outside), walk `parents` up to the first visible key and `focusKey` it; else just clear `focusedKey`.
5. **Announcements**: one `<LiveRegion>` rendered unconditionally as the root's last child (outside every treeitem). Track `watch: { parentId: string | null; kind: 'expand' | 'retry' | 'more' } | null`, set when the user expands (via key or toggle click), retries or loads more. Effect on `flat` + `watch`:
   - pending = (expand/retry) a `loading:<id>` item exists, or (more) the overflow of that level has `loading: true`;
   - while pending, start a 300ms timer once; when it fires and still pending → message `t('treeView.loading')`;
   - an `error:<id>` item for the watched parent → message `t('treeView.loadError')`, clear watch;
   - neither pending nor error → clear watch and timer; leave the message as is (success is silent; next announcement replaces it).

````md
# `<TreeView>` — lazily loaded hierarchy, as a file list or an org chart

A WAI-ARIA tree for hierarchies the app loads level by level (organization units, folders, categories). Two views of the same data: `list` (file-explorer rows) and `chart` (classic top-down org chart). The app owns fetching, caching and errors; TreeView owns rendering, keyboard, focus, selection and the loading / error / "N more" rows.

```tsx
import { TreeView, type TreeViewNode } from '@eocrm/design-system';

const [expanded, setExpanded] = useState<Set<string>>(() => new Set());
const children = useQueries({ queries: [...expanded].map((id) => unitsQuery({ parent: id })) });
const byId = new Map([...expanded].map((id, i) => [id, children[i]]));

<TreeView
  aria-label="Organization structure"
  view="list" // or "chart"
  roots={roots.map(toNode)}
  childrenOf={(id) => {
    const q = byId.get(id);
    return q?.isError ? { error: true } : q?.data?.units.map(toNode); // undefined = loading
  }}
  expandedIds={expanded}
  onExpandedChange={(id, open) =>
    setExpanded((prev) => {
      const next = new Set(prev);
      if (open) next.add(id);
      else next.delete(id);
      return next;
    })
  }
  selectedId={selectedId}
  onSelect={openDrawer}
  onRetry={(id) => byId.get(id)?.refetch()}
  overflowOf={(parentId) =>
    hiddenCount(parentId) > 0 ? { label: t('more', { count: hiddenCount(parentId) }) } : null
  }
/>;
```

<!-- props:start -->
<!-- props:end -->

- **Lazy by contract.** `childrenOf(id)` is called only for expanded nodes: return the array once loaded, `undefined` while loading (a "Loading…" row), `{ error: true }` on failure (a "Couldn't load. Retry" row; actionable only with `onRetry`). Start the fetch when an id appears in `expandedIds`.
- **Controlled.** `expandedIds` / `onExpandedChange` and `selectedId` / `onSelect` are controlled. Omit `onSelect` for a tree without selection. Selection never follows focus: arrows move, Enter / Space / click select.
- **Overflow.** `overflowOf(parentId)` (`null` = root level) adds a muted "N more not shown" row at the end of a level. Add `onLoadMore` to make it actionable and `loading` while it fetches; focus then moves to the first new item.
- **Rows** are named by `label`; `content` is visual only and must not contain buttons, links or inputs (a treeitem's content is not separately reachable). Put actions in the selection target (a drawer, a detail pane).
- **Keyboard — list:** ↑/↓ move, → expands or enters, ← collapses or goes to the parent, Home/End, Enter/Space select, type to jump. **Chart:** ↓ expands or enters, ↑ collapses or goes to the parent, ←/→ move between siblings; the tree describes these keys to screen readers.
- **Screen readers:** one tab stop; levels, positions and expanded state come from ARIA. A slow (≥ 300ms) user-triggered load is announced once ("Loading…"), a failure is announced; success is silent and focus is kept or moved to the new items.
- **Sizing.** `list` grows with its content — put it in a scrolling parent for long trees. `chart` fills its parent's width and scrolls horizontally inside itself when the chart is wider; the focused box scrolls into view.

#### When NOT to use

- ❌ App navigation → `Rail` (with `Rail.Group`).
- ❌ A flat or two-level list → `Card.List`, `Table`, `Accordion`.
- ❌ Multi-select / checkbox trees, drag-and-drop reordering — not supported.
- ❌ A whole tree that is already in memory and small → still fine, but return arrays immediately from `childrenOf`; don't fake loading.

#### Anti-patterns

- ❌ Buttons, links or menus inside `content`.
- ❌ Returning `undefined` forever on a failed fetch — return `{ error: true }`.
- ❌ Selecting on focus (opening a drawer on every arrow key).
- ❌ Wrapping the chart view in a fixed-width scroller — it scrolls itself.
````
