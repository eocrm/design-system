# DateTile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `<DateTile>`, a read-only calendar-style date display with combinable variants, in `@eocrm/design-system`.

**Architecture:** All date logic lives in a pure model, `dateTileModel.ts`. It turns the props and a "now" into display parts: labels, relative state, accessible name and the `dateTime` attribute. The model normalises every input to an ISO calendar day in the effective time zone first, then formats with `_internal/isoDay.ts` in UTC, so the host time zone can never shift the day. `DateTile.tsx` only renders those parts.

**Tech Stack:** React 19, TypeScript, SCSS modules + component tokens, `Intl.DateTimeFormat`, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-08-date-tile-design.md`

## Global Constraints

- Library Hard rules (`packages/design-system/CLAUDE.md`):
  - tokens only, with no raw px or colour, in `.module.scss`;
  - no margin or position, and `width` only `100%`;
  - `forwardRef` + native prop spread;
  - user-facing strings via `useTranslation`, with locale from `useLocale`.
- Root element is `<time dateTime="…">`. The visible abbreviations are `aria-hidden`. A `VisuallyHidden` full text carries the accessible name. There is no tab stop and no interactivity.
- `'YYYY-MM-DD'` input is a calendar day and never shifts with the time zone. A `Date` or ISO timestamp input is shown in `timeZone` when given, otherwise in the device's time zone.
- Default props: `layout='stacked'`, `size='md'`, `surface='filled'`, `show='weekday'`, `relative=true`, `color` = accent (no palette colour).
- "Today" look:
  - `stacked`+`filled`: accent fill (`--color-accent` background, `--color-accent-fg` text).
  - `plain`: no box; text in `--color-accent`.
  - `page`: band keeps `color` (default accent); the tile gets an accent outline.
- Past dates: text in `--color-fg-muted`, everything else unchanged. Never use `opacity`, which breaks contrast.
- `sm` never renders the bottom line.
- Core invariant (root `CLAUDE.md`):
  - tests;
  - playground demo + route + `navItems.ts` + `ComponentsIndex.tsx` + `overviewSchematics.tsx` + `ComponentName` union;
  - `src/index.ts` export;
  - `docs/components/DateTile.md` + `AI-PRIMER.md` line;
  - CLUSTERS `DateTile: 'Display'` in both `src/_meta/manifest.ts` and `scripts/generate-manifest.mjs`, then `npm run build:manifest`.

## Review Focus

1. **A `Date` near midnight in a time zone that differs from the device's.** `2026-11-12T23:30:00Z` with `timeZone: 'Asia/Tokyo'` must show **13**. The same instant with `timeZone: 'America/New_York'` must show **12**. Test in Task 1.
2. **A day string in a negative-offset host zone.** `'2026-11-12'` must show 12 even when `process.env.TZ` is `America/Los_Angeles`. Task 1 runs the whole model suite under a pinned `TZ`.
3. **Ranges that cross a month or a year:**
   - `2026-11-28`→`2026-12-02` gives day `28–2` and a month line holding both months.
   - `2026-12-30`→`2027-01-02` with now in 2026 shows the year. Test in Task 1.
4. **Invalid or inverted input:**
   - `date: 'nope'` makes the model throw `[DateTile] invalid date`. The component catches nothing, so this fails loudly, like `parseIsoDay`.
   - `end` before `date` is ignored, so the tile renders as a single day with no throw. Test in Task 1.
5. **The relative boundary is computed in the effective time zone, not the device's.** Now `2026-11-12T23:30:00Z`, `timeZone: 'Asia/Tokyo'` and date `'2026-11-13'` must give state `today`. Test in Task 1.

```ts
export type DateTileInput = Date | string;
export type DateTileShow = 'weekday' | 'time' | 'weekday-time';
export type DateTileRelative = 'today' | 'tomorrow' | 'ongoing' | 'past' | null; // yesterday is 'past' + the 'Yesterday' word
export interface DateTileWords {
  today: string;
  tomorrow: string;
  yesterday: string;
  ongoing: string;
}
export interface DateTileParts {
  month: string; // visible month line, uppercase is CSS's job: 'Nov', 'Nov 2027', 'Nov – Dec'
  day: string; // '12' or '12–14'
  bottom: string | null; // weekday / time / 'Today' / 'Thu–Sat' / 'Today · 14:30'; null when nothing applies
  relative: DateTileRelative; // 'today' and 'ongoing' both get the today look; 'past' gets muted
  label: string; // accessible name, e.g. 'Today, Thursday, 12 November 2026, 14:30'
  dateTime: string; // '2026-11-12' for a day string, Date#toISOString() for a timestamp; range → start
}
export function dateTileParts(opts: {
  date: DateTileInput;
  end?: DateTileInput;
  show: DateTileShow;
  relative: boolean;
  now: Date;
  timeZone?: string;
  locale: string;
  words: DateTileWords;
}): DateTileParts;
```

- [ ] **Step 3: Implement `dateTileModel.ts`.**
  1. Normalise each input to `{ iso: 'YYYY-MM-DD', instant: Date | null }`.
     - A string matching `/^\d{4}-\d{2}-\d{2}$/` becomes a day (`instant: null`).
     - Anything else is converted with `new Date(...)`.
     - An invalid result throws `[DateTile] invalid date: <input>`.
     - An instant's ISO day comes from `Intl.DateTimeFormat('en-CA', { timeZone, year:'numeric', month:'2-digit', day:'2-digit' })`. `timeZone` undefined means the device zone.
  2. Get "today" the same way from `now`. Shift days by ±1 with `parseIsoDay` + UTC date math. Compare ISO strings lexicographically.
  3. Format all labels from the ISO days with `formatIsoDay`/`formatIsoRange`:
     - month `{ month: 'short' }`; add `year: 'numeric'` when any shown day's year differs from today's;
     - day `{ day: 'numeric' }`, joining a range with an en dash `–`;
     - weekday `{ weekday: 'short' }`;
     - label `{ weekday: 'long', day: 'numeric', month: 'long', year: 'numeric' }`.
  4. Format time from the instant with `Intl.DateTimeFormat(locale, { hour: 'numeric', minute: '2-digit', timeZone })`.
  5. Join the bottom line with `' · '`. Prefix the label with `` `${word}, ` `` and add the time with `', '`.
  6. Strip a trailing `.` from short month and weekday names. Some locales (ru `нояб.`) add one, and the tile is a label, not prose.

- [ ] **Step 4: Run the tests; expect them to pass.** Adjust only the expected Intl strings in the `label` rows to the exact runtime output, and never the behaviour.
