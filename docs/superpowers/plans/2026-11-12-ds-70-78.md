# DS-70..78 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Button `loading`, the collapsed Rail badge dot, four Chart/ScatterChart props, the new `LaneChart` and the new `ChartSync` group on one branch.

**Architecture:** The small tasks are additive props on existing components. `Chart.tsx`'s
interaction shell (zoom, viewport, selection, inspection, keyboard, pointer, tooltip and table toggle) is
extracted into a hook so `LaneChart` reuses it unchanged. `LaneChart` stacks per-lane `computeLayout`
results on a shared gutter. `ChartSync` is a context-held external store that every x-axis chart
publishes its inspected x to and echoes from.

**Tech Stack:** React 19 + TypeScript, SCSS modules + component tokens, d3-scale/d3-shape, Vitest
(`unit` = Node `*.test.ts`, `dom` = jsdom `*.test.tsx`), Testing Library, playground (Vite).

**Spec:** `docs/superpowers/specs/2026-11-12-ds-70-78-design.md`. Read it before any task.

All paths below are relative to `packages/design-system/` unless they start with `packages/` or `docs/superpowers`.

## Review Focus

1. **Button `loading` inside a `<form>` with `type="submit"`:** Enter in a text field or a click must not submit the form while loading. `aria-disabled` alone does not block implicit submission. Test in Task 1.
2. **`includeZero={false}` with all-null or single-value data:** no `NaN` ticks; falls back to the existing `min === max` widening. Test in Task 3.
3. **`integerValues` on a large range (0–2000):** ticks stay at the normal density (whole numbers, not 2001 ticks); on 0–1 they are exactly `[0, 1]`. Test in Task 4.
4. **`selectOn="tap"` on touch when the finger scrolls the page:** a moved press (past slop) neither selects nor clears. Test in Task 5.
5. **ChartSync when the source chart unmounts mid-hover, or `categoryValues` has the wrong length:** receivers drop the echo; a length mismatch warns once in dev and falls back to label matching. Tests in Task 12.
