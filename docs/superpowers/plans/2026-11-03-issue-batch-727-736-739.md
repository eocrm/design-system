# Issue batch #727 #736 #737 #738 #739 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix five open consumer issues in `@eocrm/design-system` on one branch:

- LinkCard button fill (#736)
- DashboardCanvas stray selection (#737)
- Timeline first-line node (#738)
- `List variant="plain"` + Text alignment inherit/logical (#727)
- `RichText onImageActivate` (#739)

**Architecture:** Each task is a localized change to one component, plus its tests, JSDoc, `docs/components/<Name>.md` (regenerate with `npm run build:docs`), and a playground demo example wherever public API is added.

**Tech Stack:** React 19, SCSS modules + tokens, Vitest (jsdom/node projects), Playwright (`tests/*.spec.ts`, root `playwright.config.ts`).

**Spec:** `docs/superpowers/specs/2026-11-03-issue-batch-727-736-739-design.md`

## Global Constraints

- Hard rules in `packages/design-system/CLAUDE.md` apply. In particular:
  - Tokens-only SCSS. A new shared value goes in `packages/design-tokens/src/tokens.json` + `npm run tokens:check`; component values go in `<Name>.tokens.scss`.
  - No layout properties on components, except `width: 100%`.
  - `:focus-visible`.
  - JSDoc on every exported prop and union member.
  - i18n via `useTranslation`, with keys in `messages.ts`, `en.ts` and `ru.ts`.
  - `||` fallbacks for accessible names.
- Test placement: cheapest environment; no exact counts on extensible collections; no redundant smoke tests.
- Vitest runs from `packages/design-system` (cwd matters). `make test` from the repo root is the full gate; read its exit code.
- Commit messages are plain conventional commits referencing the issue, e.g. `fix(LinkCard): … (#736)`. No Co-Authored-By, Claude-Session or "Generated with" lines.
- Use "Addresses #N", never closing keywords. Issues are closed after release.

## Review Focus

1. **Text alignment default change (#727b).** Library components that render `Text` inside a centred UA context (a raw `<button>`, a centred cell or badge) must look unchanged. → Task 3 audits and pins.
2. **`Text align="end"` inside RTL (`dir="rtl"`).** It must align to the left edge. → Task 3 test asserts the `text-align: end` class, not a physical value.
3. **DashboardCanvas move-drag clicks inside widget bodies (#737).** Buttons and inputs in a widget body must still receive clicks and focus. → Task 2 test: a click on a body button still fires.
4. **RichText with `onImageActivate` unset (#739).** Markup must be byte-identical to today. → Task 6 test.
5. **Timeline compact + a two-line header (#738).** The node centres on line 1, not on the block. → Task 5 Playwright asserts against the first line's rect.
